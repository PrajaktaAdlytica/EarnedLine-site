A shared record, different responsibilities.

CFO, billing operations and RevOps can review the same evidence with distinct questions and decision authority.

02 / In context

For the CFO: establish incremental value.

Separate previously unknown findings from existing reports and known exceptions. Include reviewer effort and data-mapping cost before judging the opportunity.

03 / In context

For billing operations: open the exception.

Put the executed term, usage coverage and affected invoice line beside the next action. Hold ambiguity and document credits before proposing a correction.

04 / In context

For RevOps: make the handoff explicit.

Compare CRM entitlements and concessions with executed terms. A CRM field is useful context; it does not supersede the signed agreement.

05 / In context

For integrators: map a narrow boundary.

Begin with permissioned exports from one billing/CRM pair. Agree stable identifiers and period coverage before assessing any production integration.
